AutoTab

Rules decide which tabs share a group. The first match wins. A domain matches that site and its subdomains. *.google.com is a wildcard. github.com/pulls matches that path. A word with no dot matches anywhere in the address.

Settings

Chrome refuses to put pinned tabs in a group, so they always stay put.

Rules

Higher rules win. Move a rule up when it should beat a broader one. Pick any color with the swatch, a hex value, or RGB. Chrome's tab strip only has nine colors, so the group uses the nearest one.
